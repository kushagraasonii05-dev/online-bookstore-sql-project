# Online Bookstore SQL Project

## Project Overview
This project analyzes an online bookstore database using MySQL to understand book sales, customer purchasing behavior, revenue, and inventory.

## Database Tables
- **Books:** Book details, prices, genres, and stock.
- **Customers:** Customer names, emails, and cities.
- **Orders:** Customer purchases, quantities, and order dates.

## SQL Concepts Used
- SELECT, WHERE, ORDER BY
- Aggregate Functions (SUM, COUNT)
- GROUP BY
- INNER JOIN and LEFT JOIN
- Primary Keys and Foreign Keys
- Window Functions (RANK)
- CASE Statements
- Views

## Business Questions
- Which customer purchased the most books?
- Which book generated the highest revenue?
- How much revenue was generated each month?
- Which books have low stock?
- Which customers have never placed an order?
- How can books be categorized by price?
